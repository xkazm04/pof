# GTAI: Uprising: art-direction round (2026-11-01)

This folder holds three complete design variants for the owner to choose the art style and settle the §10 open decisions in `../pitch.md`. The variants are DEAD INK (A/2's risograph noir, 3D with a riso post-process), SODIUM (pre-rendered Blender sprites over a 3D block city) and SATURDAY MORNING MASSACRE (vector cutout rigs built in code).
Each `variant-N/` holds `DESIGN.md` (art idea, rules, Blender-plus-code production recipe and feasibility verdict, the game as that variant reads it, sample lines, verbatim prompts), three 16:9 gameplay frames, a Rivet concept and `prompts.json` with a generation note per image.
Open `index.html` from disk to compare the variants side by side. It needs no network except Google Fonts.
The images are concept art only (fleet decision 2026-11-01: production assets are Blender and code), rendered with qwen-image through PoF's `/api/visual-gen/generate-2d`; Leonardo was out of API tokens, and two shots needed one retry each for gameplay scale.
