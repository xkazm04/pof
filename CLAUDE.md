## Fleet Shared Memory (cross-session coordination)

Multiple Claude sessions often work in this repo in parallel (Personas Fleet
orchestration, plus the user's own sessions). The coordination surface is
**[`.claude/fleet-memory.md`](./.claude/fleet-memory.md)** — key decisions,
deliveries, and reusable conventions, one line each.

Rules for every session:
1. **At task start:** read `.claude/fleet-memory.md`. Follow its CONVENTION
   lines; do not silently contradict a DECISION line.
2. **At task end:** append **at most 2 one-line entries**
   (`- [YYYY-MM-DD] [area] KIND: one sentence`) — a DECISION and/or DELIVERED,
   plus a CONVENTION only if you established a genuinely reusable pattern.
3. **Never** paste logs, diffs, or file contents into it; never rewrite or
   delete other sessions' lines (except pruning oldest DELIVERED lines when
   the file exceeds ~200 lines).
4. Appending is the only edit mode — if your tooling can't append safely,
   skip the write rather than risk clobbering parallel writers.
